# Miniature aerei AXIS

Cartella per immagini locali WebP/PNG autorizzate, a colori, con orientamento e inquadratura coerenti. Le immagini effettive non sono ancora disponibili: nessun file War Thunder è stato copiato. Registrare ciascun file verificato in `js/axis/aircraft-profiles.js`, con fonte, autore e licenza/permesso. Non usare copie delle risorse Gaijin senza aver verificato il diritto alla redistribuzione. Il catalogo non richiede immagini da host esterni.
