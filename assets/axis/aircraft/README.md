# Miniature aerei AXIS

16 miniature fornite dal giocatore in aerei_asse.zip, convertite in WebP a 512 × 256 pixel con trasparenza e inquadratura originali. Fonte: War Thunder / Gaijin; diritti di ripubblicazione non verificati indipendentemente. Le associazioni e le varianti sono registrate in `js/axis/aircraft-profiles.js`. Mancano Ba.65 M, Bf 109G, Re.2001 OR e CANT Z.506. Nessun caricamento esterno delle immagini.
