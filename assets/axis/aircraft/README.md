# Miniature aerei AXIS

16 miniature fornite dal giocatore in aerei_asse.zip, convertite in WebP a 512 × 256 pixel con trasparenza e inquadratura originali. Fonte: War Thunder / Gaijin; diritti di ripubblicazione non verificati indipendentemente. Le associazioni e le varianti sono registrate in `js/axis/aircraft-profiles.js`. 19/20 modelli coperti: Bf 109G e Re.2001 OR riutilizzano le miniature G-14/AS e CB. Manca CANT Z.506. Ba.65 M utilizza ba65m.webp, miniatura fornita dall'utente. Nessun caricamento esterno delle immagini.
